# AI 상담 가이드 매뉴얼

정적인 안내 페이지로 상담사 화면, 관리 메뉴, 용어 해설, 주의사항을 한 곳에서 확인할 수 있습니다.

## 파일 구조
- `index.html`: 메인 랜딩, 카드 검색으로 각 메뉴 바로가기 제공
- `counselor.html`: 상담사 화면 예시(로그인, 실시간 상담 STT)
- `management.html`: 관리 메뉴 예시(대시보드, 상담평가)
- `glossary.html`: 용어 해설 예시 모음
- `caution.html`: 운영 시 주의사항 체크리스트
- `style.css`: 공통 스타일 및 아코디언 네비게이션 스타일
- `script.js`: 네비게이션 아코디언 제어, 활성 상태 동기화, 카드 검색 필터

## 사용 방법
1. 로컬에서 `index.html`을 브라우저로 엽니다.
2. 좌측 아코디언 메뉴를 펼쳐 원하는 항목(1~4번)과 하위 항목(1.1, 1.2 등)을 선택하면 해당 예시 페이지로 이동합니다.
3. 메인 페이지의 검색창으로 카드 텍스트를 실시간 검색할 수 있습니다.

## 참고
- 모든 페이지는 정적 HTML/CSS/JS로 구성되어 있어 별도 빌드나 서버가 필요 없습니다.
- 네비게이션 활성 상태는 현재 페이지와 해시(#섹션)에 따라 자동으로 동기화됩니다.

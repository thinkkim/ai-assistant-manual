1. 상담사 화면

상담사 화면 예시

박원장 원장 | 역삼역의원 🔔

상담사 시점에서 로그인, 실시간 상담 STT를 진행할 때 필요한 화면 구성을 살펴보세요. 각 화면은 실제 사용 흐름대로 스크린과 주요 포인트를 제공해 줍니다.

1.1 로그인

안전한 로그인 플로우

이메일·휴대폰 기반의 로그인과 2단계 인증 코드를 입력하는 화면입니다. 세션 만료 시 재로그인 안내와 보안 알림 모달 예시를 포함했습니다.

로그인 화면 예시
  • 입력값 유효성 검사와 오류 메시지 디자인
  • 2단계 인증 코드 입력 필드와 타이머 표시
  • 장치 기억하기 옵션 및 보안 알림 배너
1.2 실시간 상담 STT

음성-텍스트 변환 상담화면

실시간 음성을 텍스트로 변환하여 상담 노트에 자동 기록하고, 키워드 태깅과 요약을 함께 제공하는 화면입니다. 상담 진행, 노트, 요약 탭으로 분리된 예시 UI가 포함됩니다.

STT 상담 화면 예시
  • 녹음/일시정지/종료 컨트롤과 상태 표시
  • 실시간 텍스트 스트림과 발화자 구분 스타일
  • 요약/액션 아이템 패널, 상담 저장 버튼 배치
